# Scalpping — Índice de experimentos

Este repositorio público estaba vacío y se conserva como **índice de proyectos experimentales** relacionados con observación de mercados y análisis de datos. No se presenta como un motor funcional independiente.

## Repositorios con implementaciones

- [LibroOrdenes-Rangos](https://github.com/augustogjmm/LibroOrdenes-Rangos) — monitor experimental de libro de órdenes.
- [CryptoAnalisis-](https://github.com/augustogjmm/CryptoAnalisis-) — indicadores técnicos y datos de Binance.
- [MTF Live Monitor](https://github.com/augustogjmm/mtf-live-monitor) — integración, datos y validaciones.
- [Carter](https://github.com/augustogjmm/Carter) — investigación y simulación.

## Contexto

La documentación se mantiene por transparencia respecto del alcance de cada herramienta. **No hay código ejecutable en este repositorio índice.** Ninguno de los proyectos vinculados garantiza resultados financieros.
